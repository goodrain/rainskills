# 默认用户结果协议

- 普通用户回复默认使用清晰、适度详细的中文，只陈述本轮已经验证的结果；字段或事实无法确认时省略，不得猜测。
- 只有用户明确要求结构化结果，或自动化/评测明确要求机器可读契约时，才输出 Skill 专属 schema。
- 默认不得展示内部状态码、枚举、对象字段、工具名、工具调用记录、YAML、JSON、原始日志或英文编排标题。
- 成功正文说明结论、已执行动作、应用/组件当前状态、已验证访问地址、与结果直接相关的端口或注意事项，以及至多一个有用下一步。
- 未完成正文说明已执行动作、当前状态、单一阻塞、简短关键证据、与阻塞直接相关的访问地址或端口说明，以及唯一下一步；没有安全且可执行的动作时省略下一步。
- 已执行动作和关键证据必须概括，不复制内部 action ledger、原始日志或重复错误全文。
- 同一字段在默认正文中只出现一次；除非用户明确询问，不附加固定下一步列表。
- 过程进度只在状态发生变化或距上一条可见消息超过 30 秒时发送；没有新事实时保持安静。
- 不得把 accepted、building、Running 或未经验证的 URL 提升为业务成功。
- 本协议只定义共享表达边界。Skill 专属 schema、状态词、成功条件、验证证据和停止条件仍以对应输出 contract 为准。
