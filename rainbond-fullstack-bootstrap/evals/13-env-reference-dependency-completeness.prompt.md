Compose 画像里有 `db`、`redis`、`api`、`worker`、`sandbox`、`plugin_daemon` 六个服务。compose 的 `depends_on` 只声明了 `api -> db`、`api -> redis`、`worker -> db`、`worker -> redis` 四条边，但各服务的 env 里还互相引用：`api` 和 `worker` 的 env 有 `SANDBOX_API_ENDPOINT=http://sandbox:8194/v1` 和 `PLUGIN_DAEMON_URL=http://plugin_daemon:5002`，`plugin_daemon` 的 env 有 `DB_HOST=db` 和 `DIFY_INNER_API_URL=http://api:5001`。请部署整套拓扑并配好组件间依赖。
